# 📊 Sales Data Calculator Using Python

##  Project Overview

The **Sales Data Calculator** is a beginner-friendly Python project developed as part of my internship learning journey at **Veda Technology**. This project analyzes a collection of sales values and calculates total sales, average sales, highest sale, and lowest sale using Python's built-in functions.

##  Objectives

- Store sales values in a Python list.
- Calculate the total sales.
- Find the average sales.
- Identify the highest sale.
- Identify the lowest sale.
- Display the results clearly.

##  Technologies Used

- **Programming Language:** Python
- **Platform:** Google Colab / Jupyter Notebook
- **Version Control:** GitHub
